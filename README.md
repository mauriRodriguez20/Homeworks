# Estructuras de Datos 2

Asignatura profundiza en el estudio y aplicación de estructuras fundamentales para el procesamiento y organización eficiente de la información en sistemas computacionales.

Árboles, grafos, tablas hash, y técnicas de manejo de memoria. Importancia de la eficiencia algorítmica, análisis de complejidad y buenas prácticas de programación orientadas a la resolución de problemas reales.
